# CTF

Min samling av løsninger, notater og erfaringer fra forskjellige Capture The Flag-utfordringer.

Målet er ikke bare å lagre flaggene, men å dokumentere hvordan oppgavene ble løst og hvilke kommandoer, verktøy og teknikker som var nyttige underveis.
